# 111 · 学习或知识问题

> 用户：英语听力不开字幕跟天书一样，一开字幕又觉得每个词都认识，这种到底咋练啊，每天能抽二十分钟左右。

## 本仓库（发布版）

你这种情况，最该练的是**“听到声音，马上认出熟词”**。英语进了句子，会连读、弱读，有些小词读得特别轻，跟你背单词时听到的样子差不少。[这里有具体例子](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)。

每天二十分钟，建议只练 **30～60 秒、带准确英文字幕的片段**：

1. **3 分钟：关字幕听两遍。** 抓“谁在说什么”，记住哪几处没听出来。
2. **8 分钟：开英文字幕，逐句对照声音。** 挑出三处“字认识，但刚才没听出来”的地方，听清楚它实际怎么读。同一句听两三遍还糊，就看字幕查。
3. **6 分钟：关字幕，重听这三处，再跟读。** 每句听完再模仿两三遍，注意哪儿连起来、哪儿轻、哪儿重。
4. **3 分钟：原速完整听一遍。** 用一句中文说出内容，再看看那三处现在能不能直接听出来。

**字幕用来查漏，查完就关掉重听。** 这样每次开字幕，都能解决一个具体的“为什么这个熟词我没听出来”。

选材料时，看字幕应该能轻松理解，关字幕至少能抓住一些短句；整段都是天书，就换简单一点的。可以从 [British Council 分级听力](https://learnenglish.britishcouncil.org/en/listen-and-watch)的生活短对话开始。

第二天先花两分钟复听昨天那三句，从看字幕的时间里挪出来。每周再听一段同难度的新材料，看第一次能听懂多少，用这个判断进步。

## 测试版（发布前的同一份规则，例子里还有个人信息）

你这种情况，很适合练**“把认识的词，从声音里认出来”**。从你的描述看，很可能卡在这一步：句子里的词会连读、读得很轻，跟背单词时听到的发音有差别。[British Council 的连读说明](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/connected-speech-part-1)

每天选 **30～60 秒、有准确英文字幕或原文**的音频，二十分钟这样分：

1. **2 分钟：复习昨天。**关字幕重听，看看昨天卡住的地方今天还能不能听出来。第一天用来选材料。
2. **3 分钟：听新片段。**关字幕听两遍，记下大意、听到的几个词，听不清的地方留空。
3. **5 分钟：对照英文字幕。**挑出两三处“明明认识，刚才却没听出来”的地方，边看边听，找出它实际怎么念。
4. **7 分钟：只练这几句。**听一句→暂停跟读→关字幕再听。模仿它的停顿、轻重和连在一起的声音。
5. **3 分钟：关字幕完整听。**用中文说出大意和两个细节。

**字幕放在核对这一步，用完就关掉再听。**每天能解决两三个“熟词听不出来”的地方，就有明确的练习收获。

材料可以先试 [British Council A2 听力](https://learnenglish.britishcouncil.org/free-resources/listening/a2)。选那种关字幕能抓到一点意思、看原文能轻松看懂的；如果只能听见零星几个词，就换更简单的。

每周拿一段同难度、没练过的音频听听，看能抓到的大意和细节有没有变多。

## 原版（不加 skill）

按你描述，**优先要练的是“听到声音，马上认出熟词”这一步。** 你认识单词的写法，但实际说话里，词会连在一起，`to、of、and` 等还经常读得很轻，听起来就和脑子里的读音对不上。这是常见的听力卡点。[英国文化协会的解释](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/connected-speech-part-1)

每天二十分钟，可以先照下面练两周。

**每天只练一段 30～60 秒、有准确英文稿的录音。** 选看稿能轻松理解、不看能抓到一些词的材料。如果完全一片空白，就换简单些的；可以从[这里的 A2 短对话](https://learnenglish.britishcouncil.org/free-resources/listening/a2)试起。

| 时间 | 怎么练 |
|---|---|
| **2 分钟：复习** | 关字幕听昨天那段，看看昨天漏掉的词今天能否认出来。第一天跳过，时间放到下面。 |
| **3 分钟：盲听** | 新片段听两遍，只记“谁在说什么”和几个关键词，漏掉的地方先留空。 |
| **8 分钟：拆卡点** | 挑最听不清的 **2～3 句**，每句重听两遍，写下听到的片段；再看英文稿，定位究竟漏了哪个词。然后看着稿听一遍，关稿再听。 |
| **4 分钟：模仿** | 听一句，暂停，跟着说一句，模仿原音的轻重和停顿。卡住时可以稍微降速，最后回到原速。 |
| **3 分钟：整段验收** | 关字幕、原速听完整段，用中文说出大意和两个细节；看看刚才那几句是否能听出来。 |

看稿核对时，尤其注意这三种情况：

- **词认识，声音没认出来：** 把前后几个词一起听、一起模仿，建立整段声音的印象。
- **词听到了，意思没跟上：** 按短语理解，例如 `at the end of the day`，练习整块反应。
- **看稿也不懂：** 查清意思；如果这种情况很多，就降低材料难度。

**字幕可以用，关键是看完之后再关掉听。** 别在同一句上硬耗十分钟；重听几次仍然卡住，就看稿找到原因。

每周拿一段**没练过、难度相近**的录音试一下：第一次能不能抓到更多内容。这个比“练熟的那段终于听懂了”更能说明进步。

## talk-normal

建议练**“听一小段 → 对照英文原文 → 关字幕再听”**，每天二十分钟就按这个循环做。

从你的描述看，卡点很可能在**把声音识别成词**：熟悉的词遇到连读、弱读，听起来就变了样。这也是[剑桥听力教学资料](https://www.cambridgeenglish.org/Images/524275-second-language-listening-where-are-we-john-field-cambridge-english-teacher-.pdf)强调的训练环节。

每天选 **30—60秒、带准确英文原文的短音频**，原文基本能直接看懂，初听能抓到几个关键词。可以先试 [British Council 的 A2 短对话](https://learnenglish.britishcouncil.org/free-resources/listening/a2)。

1. **2分钟：复习昨天的句子。** 关字幕回听，听完说出意思。第一天用这段时间选材料。
2. **3分钟：新片段裸听两遍。** 记下大概主题、听到的词；模糊处记个时间点，继续听。
3. **8分钟：拆开最模糊的3句。** 每句先听两遍，写下听到的片段，再看英文原文。圈出“看得懂、听着模糊”的部分，边看边听，找到声音对应的位置，然后盖住文字再听。
4. **4分钟：逐句模仿。** 播放一句、暂停、跟着说，重复两三次。重点模仿哪里连起来、哪里读得轻、哪里重读。
5. **3分钟：关字幕完整回听。** 用正常速度播放，再用中文说出大意和两个细节。

**字幕就放在第3步当核对工具。** 对照以后，再关掉字幕认出那几个词，是每天最值得花时间的地方。

每周用一段同难度的新音频，记录第一遍听到的主题和细节，观察进步。今天先截45秒，练通其中3句。

## 好好说话 haohao-shuohua

你这个情况，很可能卡在**“熟词放进句子里，就认不出声音了”**。英语有连读、弱读，词和词之间也没有清楚的停顿，跟背单词时听到的发音差不少。这种“看文字懂，听声音懵”的落差，教学资料里也有提到。[英国文化协会的解释](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/connected-speech-part-1)

**每天二十分钟，先练透一小段。** 选 **30～60 秒、有准确英文字幕或原文**的音频：看原文基本能懂，关掉字幕还能抓到一点内容。完全听不出在说什么，就换简单一点的。

可以先按这个安排练：

- **2 分钟：复听昨天那段。** 关字幕，看看昨天卡住的地方今天能不能听出来。第一天略过。
- **3 分钟：听新片段两遍。** 先抓“谁在说什么”，记下两三处没听清的位置。
- **7 分钟：处理卡住的句子。** 每句重听两三遍，试着写下听到的词，空着的地方留空。然后看英文原文，找到具体漏了哪几个词，再对着原文听它们实际怎么发音。两三遍还听不出，就直接核对。
- **5 分钟：模仿，再关字幕听。** 听一句，暂停，照着它的重音和节奏说一句；随后藏起文字，重听这句话。
- **3 分钟：原速听完整段。** 不看字幕，用中文说出大意和一两个细节，不要求逐字翻译。

核对时留意一个区别：**熟词没听出来，就多听它在整句话里的发音；词都听到了，却来不及理解，就把句子意思弄清，再整句复听。** 如果看原文也要琢磨半天，先降低材料难度。

字幕可以放心用，**核对完再关掉复听**就行。每天解决两三处具体的卡点，量已经够了，不用把整段全部听写下来。

今天可以先试试[这组带原文的短对话](https://learnenglish.britishcouncil.org/free-resources/listening/a2/four-conversations)。每周另外挑一段同难度的新材料，看看第一遍能抓住的内容有没有变多，避免把“背熟了这段”当成听力进步。

## Humanizer-zh

你这个情况很常见：**眼睛认识这些词，耳朵还没熟悉它们在句子里的声音。** 英语里词会连在一起，部分音会变轻、变短，所以实际听到的，和你脑中“一个个单词的读音”有差距。[英国文化协会的解释](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/connected-speech-part-1)

建议你先练这个顺序：**关字幕听 → 开英文字幕找卡点 → 对着声音练 → 再关字幕听。** 每天二十分钟可以这样分：

| 时间 | 做什么 |
|---|---|
| **3分钟** | 选一段 **30—60秒**的音频，关字幕听两遍。只抓“谁在说什么”，漏掉的先放过去。 |
| **5分钟** | 看英文字幕，找出 **2—3处“明明认识却没听出来”的短语**。对着音频确认：哪个词变轻了，哪些音连起来了？ |
| **8分钟** | 集中练这几处：听一句、暂停、模仿一句，再关字幕听。卡住可以暂时降速，最后回到原速。 |
| **4分钟** | 关字幕完整听一遍，用中文说出大意和两个细节。第二天开始时，再复听昨天这段。 |

开字幕之后，最值得多做一步的是：**“原来这几个词，实际听起来是这样。”** 把文字和声音对上，再关字幕确认自己能认出来。

材料先选声音清楚、有准确英文文本的短对话。初听至少能抓到一些关键词；如果完全不知道在讲什么，就换更容易的。可以从 [British Council 分级听力](https://learnenglish.britishcouncil.org/free-resources/listening)里的 A2 或 B1 试起，不合适再调整。

暂时不用整篇听写，也不用每句都磨到百分之百。每天弄清两三处就行。**每周拿一段没练过、难度相近的材料听一次**，看第一遍能抓住的信息有没有增加；当天练熟一段，容易混入记忆，隔天和新材料更能看出进步。

## humanizer（英文原版）

按你的描述，很可能是**书面词汇已经认识，但从声音里认出它们还不够熟练**。英语说话时会连读、弱读、省音，单词之间也没有清楚的“空格”，所以熟词照样可能听不出来。[剑桥的听力教学说明](https://www.cambridgeenglish.org/Images/524275-second-language-listening-where-are-we-john-field-cambridge-english-teacher-.pdf)也提到了这个问题。

你可以每天练一段 **30～60 秒、有准确英文字幕或原文的音频**。选材标准：看原文能轻松理解整句，关字幕能抓到一些词和信息。完全一团糊，就换简单一点的。

二十分钟这样分：

1. **2 分钟，复习昨天。** 不看字幕，重听昨天最难的两三句。第一天直接跳过。
2. **2 分钟，盲听新片段。** 听两遍，只抓“谁在说什么”，记几个听到的词，空缺可以留着。
3. **8 分钟，修补卡点。** 挑三句没听清的，每句重听两三次，再看英文原文。找出具体漏在哪里：哪个熟词没认出来？哪几个词连在一起？随后边看边听，把文字和声音对上。
4. **5 分钟，关字幕重听。** 对这三句“听一句→暂停模仿一句→再听一句”。模仿它的节奏和轻重；必要时稍微降速，最后回到原速。
5. **3 分钟，完整检查。** 关字幕听整段，用中文说出大意，再记下今天两三个“认识却没听出来”的短语。

**字幕放在中间用：先听，再核对，最后关掉听。** 某句反复听仍然卡住，就查原文，别把二十分钟全耗在猜一句上。也不用每天把整段逐字听写完。

今天可以试试 British Council 的 [Changing plans](https://learnenglish.britishcouncil.org/free-resources/listening/a2/changing-plans)，是带英文原文的 A2 对话，先取前半分钟就够。

先照这个安排练两周。每周挑一段同难度、没练过的材料，看看**第一次听能抓到的信息有没有变多**，用这个判断进步。
