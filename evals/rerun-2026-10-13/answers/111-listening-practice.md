# 111 · 学习或知识问题

> 用户：英语听力不开字幕跟天书一样，一开字幕又觉得每个词都认识，这种到底咋练啊，每天能抽二十分钟左右。

## 第 1 遍

### 本仓库 + AGENTS.md

重点练**“听到声音，就能认出熟词”**。你多半卡在这儿：词写出来认识，连起来、读得很轻时就听不出来了。[这里有连读、弱读的例子](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)。

每天选 **30～60秒、有准确英文字幕或原文的日常对话**，照这个二十分钟流程练：

1. **3分钟：关字幕听。** 听两遍，抓“谁在说、在聊什么”，记下卡住的位置。
2. **8分钟：挑两三句查漏。** 每句先重听两次，再看英文原文，找出“认识却没听出来”的词。对着原文听一次，随后遮住，再听。
3. **5分钟：听一句，跟着说一句。** 模仿哪里重、哪里轻、哪些词连在一起，每句两三遍。
4. **4分钟：关字幕听整段。** 听完用中文说出大意，再回听最卡的那一句。

**字幕就这样用：卡住时看，看完马上关掉重听。** 特别留意原先漏掉的词，现在能不能从声音里听出来。

第二天从前三分钟里拿一分钟回听昨天那段。每周再听一段同难度的新材料，看第一次能抓到多少内容，用这个判断进步。

材料可以先试 [British Council 的 A2 日常听力](https://learnenglish.britishcouncil.org/free-resources/listening/a2)。选那种关掉原文还能抓到一点内容、看原文基本都懂的难度。

### 本仓库（只装 skill）

就练短片段：**先盲听，再对英文字幕，再关字幕听。**

按你描述，多半是**看着认识的词，耳朵还没认熟**。英语说话时词会连起来，有些音读得很轻，跟背单词时听到的发音差不少。[英国文化协会的说明](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/connected-speech-part-1)

每天20分钟，可以这样安排：

1. **3分钟：关字幕听。** 选30—60秒的片段，听两遍，抓大意，记下两三处听不清的地方。
2. **5分钟：对英文字幕。** 找出“这词我认识，刚才却没听出来”的地方，边看边听，留意它在这句话里怎么读。
3. **8分钟：专练最卡的2—3句。** 每句都按“看文字听 → 遮住文字听 → 暂停模仿一遍”来做。卡住可以暂时降到0.8倍速，最后回原速听。
4. **4分钟：关字幕听整段。** 再用中文说出大意，检查刚才卡住的地方现在能不能听出来。

材料选**英文稿大多看得懂、盲听能抓到一点意思**的日常对话或短讲解。整段完全像天书，就换简单一点的。

第二天从开头3分钟里拿1分钟，复听昨天最卡的两句。每周找一段同难度、没练过的材料，看第一遍能抓到的信息有没有变多——这个最能看出进步。

### 原版（不加 skill）

这种情况很常见：**你看到拼写能认出词，但还不熟悉它们连读、弱读之后的声音。** 练习重点就是把“认识的词”和“实际听到的声音”对上。

每天二十分钟，练一段 **30—60秒、有准确英文字幕的生活对话**就够。选打开字幕后基本能看懂的材料。

1. **2分钟：关字幕听两遍。** 抓“谁在说什么”，允许漏词，记住哪里听成了一团。
2. **8分钟：逐句核对。** 每句先听，再看英文字幕，找出“明明认识却没听出来”的地方；看着文字再听两遍，注意词之间怎么连起来。卡住两三遍就核对，别一直猜。
3. **6分钟：挑三句模仿。** 看字幕听一句，暂停后照着说一句，再关字幕听。重点模仿重音、停顿和连读，不必追求口音完美。太快可以短暂降到0.8倍，最后回原速。
4. **4分钟：关字幕听整段，再复听昨天那段。** 看看能否跟上意思，不要求逐字听全。

**字幕可以用，关键是核对完以后，再关掉听。** 一直开着字幕容易变成阅读练习，一直关着又可能不知道自己漏在哪。

每周找一段没练过、难度相近的材料，裸听一次，看看第一遍能抓到多少意思。用这个判断进步，比“练熟的那段终于听懂了”更可靠。

### talk-normal

你要练的是**听声音认出熟词**。你已经熟悉词的拼写，接下来要把它们和连读、弱读时的实际发音对应起来。

每天20分钟，练一段 **30～60秒、带英文字幕的日常对话**，内容熟悉、词汇基本认识就行：

1. **3分钟：关字幕听两遍。** 抓大意，记住在哪两三处跟丢了。
2. **4分钟：开英文字幕核对。** 找到听漏的地方，边看边听，注意几个词连起来实际怎么念。
3. **10分钟：集中练那两三句。** 每句按“看字幕听一次 → 关字幕听两次 → 模仿说一次”循环。尽量跟上原声的停顿、重音和节奏。
4. **3分钟：整段关字幕再听。** 听完用中文说出大意，再确认刚才卡住的句子能否听清。

**字幕用来核对声音，核对完就关掉。** 同一段可以练两三天；隔天还能听清，才算比较稳。每周再找一段相近的新材料盲听，看看能抓住的内容有没有增加。

今晚就选30秒开始，把两三句里的熟词听清。

### 试验版 + AGENTS.md（没有发布）

每天练一小段，**先听、再看英文字幕核对、最后关字幕重听**。你这种情况，很适合练“把熟词和声音对上”：英语里的连读、弱读，会让认识的词听着变样。[连读示例](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)

选一段 **30–60秒、有准确英文字幕或原文的短对话**，二十分钟这么分：

- **3分钟：关字幕听两遍。** 抓谁在说什么，记下卡住的位置。
- **7分钟：看原文，逐句对着听。** 卡住的句子重复两三遍，留意熟词实际怎么读，比如 *going to* 连起来常像 *gonna*。
- **5分钟：关掉文字，听一句、暂停、模仿一句。** 跟着原音的节奏，把几个词连起来说。
- **5分钟：原速完整听。** 用中文说出这段的大意，再回听最卡的两句。

材料选“看原文基本都懂，关字幕能抓到一点意思”的；完全像天书就换简单一点的。可以从[英国文化协会的 A2 短对话](https://learnenglish.britishcouncil.org/free-resources/listening/a2)试起。

第二天用开头一分钟复听昨天那段。每周再找一段没练过的、难度差不多的音频，看看能不能多听懂几个完整短句。

### 试验版（没有发布）

你这种情况，适合练 **“先听 → 看英文字幕找卡点 → 关字幕再听”**。

按你描述，多半是词看得懂，但听到声音时认不出来。英语里的连读、弱读，会让熟词听起来跟单独背单词时很不一样。[英国文化协会的例子](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)就展示了这种变化。

每天二十分钟，我建议这样练。**只选一段30—60秒、有准确英文字幕或原文的音频**：

1. **3分钟：先整段听。**  
   不看字幕，听两遍，抓“谁在说什么事”。第二天起，拿其中一分钟复听昨天的片段。

2. **8分钟：处理听不出来的句子。**  
   挑三四句，每句重听两三次，再看英文原文。重点找：**“明明认识，这里怎么就没听出来？”** 对着文字再听，听清哪些词连在一起、哪些声音很轻，然后遮住文字重听。

3. **5分钟：一句一句模仿。**  
   播一句，暂停，跟着说一句。模仿它的停顿、重音和连读。先看文字说，再遮住说。

4. **4分钟：关字幕整段听。**  
   听完用中文说说内容，再回听两处最容易漏掉的地方。到点就结束，剩下的留明天。

**字幕可以用，关键是看完以后要回到声音上。** 每次都做到“这个词原来是这么读的”，比一直盯着字幕看更贴合你现在的卡点。

材料先选日常短对话，难度以“不看字幕也能抓到一点内容”为宜。今天可以从这篇带原文的 [Four conversations](https://learnenglish.britishcouncil.org/free-resources/listening/a2/four-conversations) 里挑一段；完全抓不到意思，就再换简单些的。

练一周后，换一段同难度的新音频，看**第一遍能听出来的内容有没有变多**。这个比练熟的那段能不能背下来，更能看出进步。

## 第 2 遍

### 本仓库 + AGENTS.md

**每天拿一小段，按“先听→对英文字幕→关字幕再听”练。**按你描述，主要卡在熟词的声音辨认：英语说起来会连读、弱读，有些音还会省掉，跟单词一个个念出来差挺多。[连读的例子](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)

选 **30～60秒、带准确英文字幕或原稿**的日常对话。关字幕能抓住一点意思，看稿基本读得懂，难度就合适。

每天二十分钟这样分：

1. **2分钟复习**：关字幕听昨天那段。第一天用来挑材料。
2. **3分钟先听**：新片段听两遍，记个大意，留意哪里听成了一团。
3. **8分钟对字幕**：挑出三句“词都认识，刚才却没听出来”的，边看边听，找出哪些词连起来了、哪些读得特别轻。
4. **5分钟关字幕练这三句**：听一句，暂停，模仿一句，尽量跟着原声的节奏。卡住就回看一下，再关掉听。
5. **2分钟完整听**：回到原速听整段，用中文说说它讲了什么。

材料可以从 [British Council 分级听力](https://learnenglish.britishcouncil.org/free-resources/listening)里挑，先找容易跟上的一级。

**练一周后，拿一段同难度的新音频，看看第一遍能听懂多少。**这样更容易看出耳朵有没有进步。

### 本仓库（只装 skill）

你这种情况，先练**把“看着认识的词”变成“听到就认得的词”**。英语里几个词会连着念，有的音很轻、有的会省掉，跟背单词时听到的声音差不少。[连读示例](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)

每天二十分钟，选一段 **30～60秒、有准确英文字幕或原文**的音频，这样练：

1. **3分钟：关字幕听两遍。** 抓“谁在说什么”，记下哪几句听糊了，先允许自己漏词。
2. **4分钟：看英文字幕核对。** 重点找“明明认识，却没听出来”的地方，再听它在原句里怎么念。
3. **9分钟：挑最卡的2～3句。** 看字幕听一遍→关字幕听→暂停后模仿着念。注意哪些词重、哪些词轻。卡住可以暂时降到0.8倍速，最后回原速听。
4. **4分钟：关字幕完整重听。** 用中文说出大意，剩下的时间回听昨天练过的几句。

**字幕可以用，关键是核对完再关掉听。** 每天重点解决两三句里听不出来的地方。

材料选“关字幕能抓到一点大意，开英文字幕基本都懂”的；完全一团糊就换简单点。可以从 [British Council 的分级听力](https://learnenglish.britishcouncil.org/free-resources/listening)挑。每周拿一段同难度的新内容，看看**第一次听能懂多少**，用这个判断进步。

### 原版（不加 skill）

你多半卡在**“听到声音，没及时认出词”**这一步。连读、弱读、语速一上来，熟词也会变陌生；字幕帮你把词认出来，所以看着就觉得都会了。这部分可以专门练。

每天二十分钟，选一段 **30～60秒、字幕准确、话题熟悉**的材料，按这个顺序来：

1. **3分钟：关字幕听两遍。** 抓大意，找到最听不清的两三句。
2. **8分钟：拆开这几句。** 每句先盲听两次，再看字幕、对着声音听。重点找出：**哪些词明明认识，刚才却没听出来？** 留意它实际怎么读，和前后词怎么连。
3. **6分钟：关字幕，逐句听＋模仿。** 听一句，暂停，照着它的轻重、停顿和连读说一句，再听原音。卡住时可以短暂降速，最后回到正常速度。
4. **3分钟：关字幕完整听。** 看能不能跟上意思，再用中文复述一两句，确认自己真听懂了。

第二天开练时，先用第一分钟回听昨天的片段，剩下时间练新的。选材时，如果看字幕也得频繁查词，就换简单一点的。

**字幕可以用，关键是看完后回到无字幕。** 每天把两三句“原来这串声音是这些词”听明白，比一直开字幕刷半小时更切合你现在的卡点。先这样练一周，观察关掉字幕后，熟词是不是更容易被耳朵抓住。

### talk-normal

**每天练一段 30～60 秒的音频，按“先听→看英文字幕核对→关字幕重听”走。**你这种情况，常见卡点是熟词在连读、弱读里认得慢，以及抓不准词与词的边界。[剑桥听力教学资料](https://www.cambridgeenglish.org/Images/524275-second-language-listening-where-are-we-john-field-cambridge-english-teacher-.pdf)

选日常对话、带准确英文稿的材料。难度以“第一遍能听出话题、抓到几个词组”为宜；全程像天书，就换简单一级的。

二十分钟这样分：

1. **2 分钟：关字幕听整段。**抓“谁在说、聊什么、发生了什么”，记下几个听到的关键词。
2. **5 分钟：拆句听。**每次放 5～10 秒，重复两三遍，写下听到的词，卡住的位置留空。
3. **4 分钟：看英文字幕核对。**找出卡住的词组，边看边听，留意哪些音连在一起、哪些词读得很轻。
4. **6 分钟：关字幕重听＋模仿。**重点练刚才卡住的三句话：听一句，暂停，照着它的节奏说一句，再听一次。
5. **3 分钟：原速听完整段。**用中文说出大意和两个细节，最后记下今天听清的一个词组。

字幕可以用，**每次核对后都回到关字幕听**。从第二天起，开头两分钟顺带复听昨天的片段；每周再拿一段同难度的新材料，观察第一遍能抓到的信息是否变多。

今天就用 British Council 的 [Changing a meeting time](https://learnenglish.britishcouncil.org/free-resources/listening/a2/changing-meeting-time)，有音频和英文稿，取前一分钟开始。

5. **3 分钟：整段关字幕再听。** 用中文说出大意，再听听那三句能不能直接认出来。

**字幕可以开，关键是看完以后再关掉听。** 卡住一句，听两三遍就看稿，找到漏在哪里，再继续。

材料可以从 [British Council 分级听力](https://learnenglish.britishcouncil.org/en/listen-and-watch)挑。选看文字能顺畅理解、裸听能抓住一些内容的；如果一句都抓不住，就换简单一点的。

每周挑一天，用同难度的新片段看看第一遍能听懂多少，这个最能看出进步。

## 第 3 遍

### 本仓库 + AGENTS.md

**每天练一小段，先听、查字幕、关字幕再听。** 你这种落差，往往是词的拼写很熟，但连读、弱读后的声音还没认熟。

选 **30～60 秒、有准确英文字幕、看字幕基本能懂**的材料。二十分钟这样分：

1. **3 分钟：关字幕听两遍。** 抓大意，记下两三句卡住的地方。
2. **5 分钟：看英文字幕找卡点。** 专门看“明明认识却没听出来”的词，边看边听，找出它实际怎么念。
3. **9 分钟：逐句练。** 卡住的句子按“听原声→看字幕→关字幕听→模仿着说一遍”循环几次。太快可以暂时放慢，最后回到原速。
4. **3 分钟：关字幕听完整段。** 听完用中文说说内容，检查刚才卡住的句子能不能听出来。

字幕就当查答案用，查完马上关掉。**最值得花时间的是那些“看着认识，听着陌生”的句子。**

每周拿一段同难度的新材料，看看第一遍能抓到的内容有没有变多——这个比把旧片段听熟更能看出进步。

### 本仓库（只装 skill）

**每天二十分钟，就拿一段30～60秒的音频，练“先听→看英文字幕核对→关字幕再听”。**

你描述的情况，多半卡在“看字认识，听声音认不出来”。英语说成句子后，词会连在一起，有些音读得很轻，熟词也容易漏掉。[英国文化协会讲的连读和弱读](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/connected-speech-part-1)就包括这种情况。

每天可以这样分：

1. **2分钟：关字幕听两遍。** 只抓“谁在说、发生了什么”，记下卡住的句子。
2. **8分钟：挑两三句拆着听。** 每句先听两遍，再看英文字幕核对。重点找：**哪个熟词刚才没听出来，它实际怎么读？** 然后盖住字幕再听。
3. **5分钟：模仿这几句。** 原声说一句，你跟一句，模仿它的停顿、轻重和连在一起的声音。
4. **5分钟：关字幕听完整段。** 试着听出刚才漏掉的词，再用一句中文说出大意。有余裕就复听昨天那段。

材料选**看英文稿基本能懂、关字幕能抓到一些内容**的。可以从[英国文化协会的分级听力](https://learnenglish.britishcouncil.org/free-resources/listening)里挑短对话，先试A2，轻松再往上换。

字幕就放在“核对”那一步用。每天练完能多认出两三处原来漏掉的声音，就有具体收获；每周换一段同难度的新材料，看看第一遍能听出多少，拿这个判断进步。

### 原版（不加 skill）

这很常见：**眼睛认得单词，耳朵还没熟悉它在真实语速里的声音。** 连读、弱读、词与词的边界，都可能让熟词听起来很陌生。练习重点是把“声音”和“认识的词”对上。

每天二十分钟，可以这样练：

1. **3分钟：关字幕听。** 选一段30–60秒、话题熟悉的材料，听两遍，抓大意，找出从哪里开始跟丢。
2. **7分钟：开英文字幕对照。** 重点找“明明认识，却没听出来”的词。把那一句单独放，看看哪些音连在一起、哪些词读得很轻。一句听三遍还卡住，就看字幕核对。
3. **7分钟：关字幕，逐句听＋跟读。** 每句听一遍，再模仿它的节奏读一遍，尤其注意刚才漏掉的部分。目标是下次听到这串声音，能直接认出来。
4. **3分钟：关字幕听完整段。** 检查原先听丢的地方能不能跟上，并用中文说出大意。第二天开练时，先复听昨天那段。

选材料时，尽量用**声音清楚、单人说话、有英文字幕**的短片。如果关字幕连大意都抓不到，就降低难度。

判断有没有进步，要看**隔天关字幕还能听出多少**。刚看完字幕觉得“全听懂了”，往往也有记住台词的成分。先按这个方法练一两周，观察熟词漏听的地方有没有减少。

### talk-normal

建议每天练一小段，按 **“关字幕听 → 对照英文稿 → 逐句回听 → 关字幕检验”** 来练。

你描述的情况，常见卡点是熟词的声音识别：单词进了句子，会连读、弱读，耳朵需要熟悉这些变化。[英协的连读说明](https://www.britishcouncil.org/voices-magazine/pop-songs-connected-speech-fluent-english)

选 **30～60 秒的日常对话**，带准确英文字幕或逐字稿，看稿能理解九成左右。每天这样分配：

1. **2 分钟：关字幕听两遍。** 抓住谁在说、聊什么，记下几个听到的词。
2. **5 分钟：对照英文稿听。** 圈出第一遍卡住的 3～5 处，注意词之间怎样连起来、哪些音读得很轻。
3. **10 分钟：集中练这几处。** 每次回放一个短句：看稿听一次 → 盖住稿听两三次 → 跟读一次，模仿重音和停顿。卡住时可暂用 0.8 倍速，最后回到原速。
4. **3 分钟：关字幕听完整段。** 检查刚才那几处能否听清，再用中文说出整段大意。

**字幕可以用，关键是每次对照后，都回到关字幕听。** 每周选一段同难度的新音频，记录第一遍能抓住的内容，观察进步。

今天就从英协的 [A2 日常短对话](https://learnenglish.britishcouncil.org/free-resources/listening/a2/four-conversations) 里取一小段开始。

### 试验版 + AGENTS.md（没有发布）

你这种就练 **“先听 → 对英文字幕 → 关字幕再听”**，每天吃透一小段。你描述的情况，多半卡在“眼睛认识这个词，耳朵还认不出它在句子里的声音”。

选 **30～60秒、带准确英文字幕的日常对话**，难度以“关字幕能抓到一点大意，看字幕基本都懂”为准。先听大意、再用字幕核对，也是[英国文化协会建议的练法](https://www.britishcouncil.org/voices-magazine/five-essential-listening-skills-english-learners)。

每天20分钟这样分：

1. **2分钟：复习昨天。** 关字幕听一遍，留意昨天卡住的地方。
2. **3分钟：听今天的新片段。** 关字幕听两遍，抓“谁在说、说什么”，漏掉的先往下听。
3. **10分钟：挑3～5句听不清的。** 每句先听两次，再看英文字幕，找到“认识却没听出来”的词；对着文字听一次，随后关字幕重听，模仿原音说一遍。
4. **5分钟：整段关字幕再听。** 听完用一句中文说出大意，还有卡点就回听那一句。

**字幕当核对答案用，看完就关掉。** 一句听三遍还卡住，就看答案，把时间花在听清它到底怎么读。每周换一段同样难度的新材料，看第一次能听懂多少，用这个判断进步。

### 试验版（没有发布）

每天20分钟，可以拿一段 **30～60秒的音频，按“先听→看英文字幕→关字幕再听”来练。**

你这种情况常见的卡点是：词在纸上认识，放进句子里连着读、读得很轻，耳朵就认不出来。要练的就是把这些熟词和实际声音对上。[英国文化协会的相关解释](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/articles/listening-top-down-and-bottom)

每天照这个安排走：

1. **3分钟：关字幕听两遍。** 抓“谁在说什么”，记下哪里开始听丢。
2. **7分钟：逐句核对。** 每次放5～10秒，先听两遍，再看英文字幕。重点找出“明明认识，却没听出来”的词，对着原声听它怎么念。
3. **6分钟：关字幕逐句重听。** 卡住就看一眼，再关掉听。听清一句后，照着原声的节奏说一遍。
4. **4分钟：原速完整听。** 用中文说出大意，再看看刚才漏掉的词，现在能不能听见。

**字幕用来核对，用完就关。** 一句听两三遍还抓不到，就看原文，别一直硬猜。

材料选日常话题、声音清楚、看原文大部分能懂的；关字幕至少能抓到一点大意。今天可以直接试试 [Four conversations](https://learnenglish.britishcouncil.org/free-resources/listening/a2/four-conversations) 里的第一段对话，页面有音频和原文。

第二天先花1分钟复听昨天那段。每周再找一段同样难度的新音频，看看第一遍能抓到的内容有没有变多，这比只看旧材料听熟了没有更能看出进步。
