## 第 103 题

用户说：物理的加速度和速度到底啥区别，我老分不清

### 回答 A

**速度**看你现在跑多快、往哪跑。**加速度**看你的速度每秒变多少、朝哪个方向变。

比如车沿直线一直以 **20 米/秒**往前开，加速度就是 **0**。踩刹车后，车速在一秒内从 **20 降到 18 米/秒**，这一秒的平均加速度大小是 **2 米/秒²**。这时车还在往前开，所以**速度向前，加速度向后**。

### 回答 B

**速度**是你现在跑多快、往哪儿跑。**加速度**是你的速度变得有多快。

比如开车走直路，每隔一秒看一次车速。

- **20 → 20 → 20 米/秒**。车一直在跑，速度没变，所以加速度是 **0**。
- **20 → 22 → 24 米/秒**。车每秒快 2 米/秒，所以加速度是 **2 米/秒²**。

刹车时，快慢在变。匀速过弯时，方向在变。这两种情况也都有加速度。

### 回答 C

**速度**是「现在跑多快、往哪儿跑」。**加速度**是「速度变化得有多快」。

想象你在车里。车沿直线一直开 **60 km/h**，速度始终一样，所以加速度是 **0**。踩刹车时，车还在往前开，车速越来越小，这时**速度向前，加速度向后**。如果车速均匀地每秒减少 3 m/s，把向前当作正方向，加速度就是 **−3 m/s²**。

（原回答这里附了一个可交互的示意图，在 Codex 里可以直接点开）

保持同样的车速转弯时，也有加速度，因为速度的**方向**在变。

### 回答 D

**速度**说的是你现在往哪儿走、走多快。**加速度**说的是这个速度变得有多快。

比如车在直路上往前开，速度每秒增加 2 m/s，加速度就是 +2 m/s²。下面三辆车在第 2 秒一样快，往后拖一秒，就能看出踩油门、匀速开和踩刹车的区别。

（原回答这里附了一个可交互的示意图，在 Codex 里可以直接点开）

车就算开到 100 km/h，只要直着匀速开，**加速度就是 0**。转弯时，哪怕仪表盘数字一样，**方向在变，也有加速度**。

## 第 109 题

用户说：我用 pandas 读 CSV，手机号前面那个 0 读完就没了，保存回去也没了……怎么让它老老实实按文本读啊？

### 回答 A

在 `read_csv` 里加 `dtype={"手机号": str}`，pandas 就会把这列当文本读，开头的 `0` 写回 CSV 时也会保留。

```python
import pandas as pd

df = pd.read_csv("input.csv", dtype={"手机号": str})
df.to_csv("output.csv", index=False)
```

把 `手机号` 换成 CSV 里的实际列名。

如果手上的 CSV 已经丢了开头的 `0`，有原始文件就重新读。如果确定号码都是 10 位，可以在保存前用 `df["手机号"] = df["手机号"].str.zfill(10)` 补齐。

### 回答 B

在 `read_csv()` 时用 `dtype` 把手机号列指定为字符串。这样 `0912345678` 读进来和写回去都会保留开头的 `0`。 [pandas 读取文档](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html) · [保存文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.to_csv.html)

```python
import pandas as pd

df = pd.read_csv("input.csv", dtype={"手机号": "string"})
df.to_csv("output.csv", index=False)
```

把 `"手机号"` 换成 CSV 里的实际列名。已经读丢了 `0` 的话，用这段代码从原始 CSV 重新读一遍。以后再用 pandas 读 `output.csv`，也加上同样的 `dtype`。

### 回答 C

在 `pd.read_csv()` 里用 `dtype` 指定手机号那列按字符串读，开头的 `0` 就会保留下来。 [pandas 文档](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html)

```python
import pandas as pd

df = pd.read_csv("原始.csv", dtype={"手机号": "string"})
df.to_csv("输出.csv", index=False)
```

把 `"手机号"` 换成你 CSV 里的实际列名。比如 `0123456789`，读进来和写回 CSV 都还是 `0123456789`。

如果 `0` 已经在上一次读取时丢了，就用这段代码从还带 `0` 的原始文件或备份重读一遍。

### 回答 D

用 `dtype={"手机号": "string"}` 指定手机号列按文本读取，前导 `0` 会保留，写回 CSV 时也会保留。

```python
import pandas as pd

df = pd.read_csv("input.csv", dtype={"手机号": "string"})
df.to_csv("output.csv", index=False)
```

把 `手机号` 换成 CSV 里的实际列名。如果已经读丢了 `0`，用这段代码重新读取仍保留前导 `0` 的原始文件或备份。

## 第 110 题

用户说：Win11 的 C 盘只剩 6G 了，但我也没装啥大东西啊。有没有比较稳的清理办法，别让我一顿删完电脑起不来了。

### 回答 A

有。先用 Win11 自带的清理工具，挑几项缓存清掉，再看 C 盘还剩多少。

1. **先清临时文件。** 按 **Win + I**，进 **系统 → 存储 → 临时文件**。等它算完，第一轮只勾「临时文件」「缩略图」「传递优化文件」里有的项，再点「删除文件」。 [微软的清理说明](https://support.microsoft.com/zh-cn/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)
2. **「下载」和「回收站」先留着。** 翻一遍里面的文件再决定。看到「以前的 Windows 安装」也先跳过，刚升级后想退回旧版本会用到它。
3. **清完还紧，就找占空间的大文件。** 回到 **存储 → 清理建议 → 大型或未使用的文件**。没装多少软件，旧安装包、视频、聊天软件存下来的文件也能攒不少。要留的可以先复制到 D 盘或移动硬盘，确认能打开，再删 C 盘那份。

系统文件交给 Windows 的清理工具。尤其是 `C:\Windows\WinSxS`，看着再大也别进去手动删。 [微软的 WinSxS 说明](https://learn.microsoft.com/zh-cn/windows-hardware/manufacture/desktop/clean-up-the-winsxs-folder?view=windows-11)

### 回答 B

用 **Win11 自带的存储设置**最稳。先清能重新生成的缓存，再看 C 盘到底是哪一类文件占得多。

1. **先清缓存。** 按 `Win + I` → **系统 → 存储 → 临时文件**。等扫描完，第一轮只勾选**临时文件、缩略图、传递优化文件**，再点「删除文件」。 [微软的清理步骤](https://support.microsoft.com/zh-cn/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows)
2. **核对勾选项。** 「下载」里是你自己下载的文件，先取消勾选。回收站打开看一遍，确认里面的文件都可以丢再清空。「以前的 Windows 安装（`Windows.old`）」先留着，它用于升级后回退。 [微软的磁盘清理说明](https://support.microsoft.com/zh-cn/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)
3. **找占空间的大文件。** 回到「存储」看哪一类最大，再点 **清理建议 → 大型或未使用的文件**。优先看旧安装包、压缩包和录屏，要留的可以移到 D 盘或移动硬盘。聊天软件占得多，就用软件里的存储管理清缓存。 [微软的存储设置说明](https://support.microsoft.com/zh-cn/windows/experience/storage-filemanagement/storage-settings-in-windows)

**系统目录交给 Windows 管理。** 手动删 `C:\Windows\WinSxS` 里的文件可能导致系统无法启动，`C:\Windows\Installer` 里的文件则用于软件更新、修复和卸载。 [WinSxS 说明](https://learn.microsoft.com/zh-cn/windows-hardware/manufacture/desktop/clean-up-the-winsxs-folder?view=windows-11) · [Installer 说明](https://learn.microsoft.com/zh-cn/troubleshoot/windows-client/application-management/missing-windows-installer-cache)

### 回答 C

有。先用 Win11 自带的「存储」清理，`C:\Windows` 和 `C:\Program Files` 里的文件别手动删。

## 第 111 题

用户说：英语听力不开字幕跟天书一样，一开字幕又觉得每个词都认识，这种到底咋练啊，每天能抽二十分钟左右。

### 回答 A

就拿 **30 秒左右的一小段**反复听。字幕可以开，开了对一下自己到底卡在哪儿，然后关掉再听。你要练的是把听到的声音跟认识的词对上。比如 *Did you* 连着说，听起来可能像 *didja*。

每天 20 分钟可以这么分：

1. **3 分钟，关字幕听两遍。** 试着用中文说说大概在讲啥。只抓到几个词也行，先记住你听到了什么。
2. **5 分钟，开英文字幕对一遍。** 挑两三处「一看就认识，刚才却没听出来」的地方，边看边听它在原句里怎么念。
3. **8 分钟，只重播卡住的那几句。** 每句先看着字幕听一遍，再关掉听两三遍，最后跟着原声念一遍。留意哪些词连在一起，哪些词被轻轻带过。
4. **4 分钟，关字幕从头听。** 看能不能听出刚才卡住的词组，再用自己的话说一遍大意。

如果 30 秒听起来全是天书，就先挑**一两句**，选关字幕时也能抓到几个词的。练几天后，换一段难度差不多的新音频，看看第一遍能不能多听出几个词组。

### 回答 B

每天 20 分钟，**拿一小段音频练「盲听 → 对字幕 → 关字幕再听」**。你要练的是听到声音就认出熟词。比如 `did you` 连起来常听着像 `didja`，眼睛认识这两个词，耳朵也得熟悉它们连起来的声音。

挑一段 **30–60 秒的日常对话**，关字幕能抓到一点大意，开英文字幕能轻松读懂。要是整段都听成一团，就从更简单的 10–20 秒对话开始。

1. **3 分钟盲听**。关字幕听两遍，用一句话说说你听懂了什么。
2. **7 分钟对字幕**。挑两三句「看得懂、刚才没听出来」的句子。每次放几秒，听一句、看一眼字幕、再关字幕听，找出哪些词读得轻，哪些词连在了一起。
3. **6 分钟跟读**。就练这两三句。听一句，暂停模仿一句，尽量跟上原音的轻重和节奏。
4. **4 分钟复听**。关字幕，把整段连着听一遍，看看刚才糊成一团的地方，现在能听出哪些词。

练一周后，找一段同难度的新对话，听第一遍就复述大意。用新片段的第一遍来判断进步。

### 回答 C

一开英文字幕就懂，可以重点练**把熟词从一句话里听出来**。平时说话，词和词会连在一起，有些音又轻又短。先盲听找卡点，再用字幕核对，最后关掉字幕重听。

挑一段 **30–60 秒**、话题熟悉、有英文字幕的音频。第一遍能抓到几个关键词，大致知道在聊什么，就适合拿来练。整段都听不出大意的话，先换一段语速更慢、发音更清楚的。

**每天 20 分钟，练一小段**

1. **3 分钟｜盲听两遍。** 第一遍抓大意，第二遍标出最卡的两三处。
2. **5 分钟｜回放，再看字幕。** 每处截一小句，先回放两三次，猜猜听到哪些词，再打开字幕，圈出漏听的熟词。
3. **7 分钟｜把声音和词对上。** 对着字幕听，跟原音读两遍，再关字幕听一次。比如 *I can do it* 里的 *can* 常读得很轻。就回放 *I can do*，听清 *I* 和 *do* 之间那个短音，再放回整句听。
4. **5 分钟｜原速关字幕听。** 听完练过的整段，用一句话复述大意。剩下的时间盲听同一节目里没听过的一小段，记下第一遍抓到的细节。

过一周，用同样难度的新片段试一遍。**第一次听就能抓到更多信息**，比练熟的那段能复述多少更能看出进步。

### 回答 D

每天用 20 分钟练一小段，专挑那些**看字幕就认识、光听却听不出来**的词。找一段 30～60 秒、有英文字幕的对话。第一遍能听出在聊什么，有几句听不清，这个难度刚好。

1. **3 分钟，关字幕听。** 听一两遍，先抓大意，记一下哪句听起来糊成一团。
2. **5 分钟，开英文字幕核对。** 挑两三处「原来是这个词」，倒回去听它在句子里怎么念。比如 *did you* 连着说，常听起来像 *didja*。
3. **7 分钟，跟读刚才卡住的几句。** 放一句、停一下、学着说一遍。留意哪几个词连在一起，哪些词念得特别轻。
4. **5 分钟，关字幕原速重听。** 听完整段，用自己的话说一句大意，再听听刚才卡住的地方，现在能不能直接认出来。

要是第一遍整段都像天书，就换一段语速慢一点、话题熟一点的。过几天找一段同样难度的新对话，看看第一遍能抓到多少。

## 第 112 题

用户说：概率里那个独立和互斥我老搞混，你拿生活里的事给我讲讲呗，先别上公式，我看到符号脑子就卡住了。

### 回答 A

**独立**是知道一件事的结果，另一件事发生的机会照旧。**互斥**是两件事最多发生一件。

想象你和朋友轮流抽奖，盒里有奶茶券和咖啡券，每抽一张就放回去摇匀。

- **独立**：你抽到奶茶券，朋友抽到奶茶券的机会还是一样，你俩也可能都抽到奶茶券。
- **互斥**：只看你抽的那一张，「抽到奶茶券」和「抽到咖啡券」只能发生一个。

### 回答 B

知道一件事发生了，另一件事的机会**还是一样**，这叫独立。要是另一件事**就没机会了**，这叫互斥。

比如咱俩每天抛硬币决定谁洗碗，正面你洗，反面我洗。

**独立**是「今晚你洗」和「明晚你洗」。今晚抛到你洗，明晚重新抛一次，你洗的机会还是一半。

**互斥**是「今晚你洗」和「今晚我洗」。今晚只抛一次，抛到你洗，就轮不到我洗了。

### 回答 C

**互斥**是两件事没法都发生。**独立**是就算你知道一件事发生了，另一件事发生的机会还是一样大。

比如奶茶店搞抽奖，箱子里的纸条有的写「奶茶」，有的写「咖啡」。

- **只抽一次。**「抽到奶茶」和「抽到咖啡」是互斥的。咖啡本来有机会，可一看抽出来的是奶茶，就知道这一抽肯定没咖啡了。
- **抽两次，第一张看完放回去，再摇匀。**「第一次抽到奶茶」和「第二次抽到咖啡」是独立的。哪怕我告诉你第一张是奶茶，第二次抽到咖啡的机会也跟原来一样，因为箱子里的纸条又都齐了。

### 回答 D

想象早餐店搞抽签。饮料盒里有豆浆和牛奶，主食盒里有包子和饭团。每种各一张签，你从两个盒子里各随机抽一张。

**互斥问「这两件事能一起发生吗？」** 饮料只抽一张，抽中了豆浆，这次就抽不到牛奶。所以抽中豆浆和抽中牛奶是互斥的。

**独立问「知道一件事发生了，另一件事的机会会变吗？」** 就算你先知道饮料抽中了豆浆，主食还是从另一个盒子随机抽，抽中包子的机会跟原来一样。所以抽中豆浆和抽中包子是独立的。
